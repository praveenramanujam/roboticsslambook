# Estimation, Mapping & Localization

A hands-on guide to the mathematics and algorithms behind robot localization and mapping. Built for students who want to understand SLAM from the ground up.

---

## How to use this book

Each chapter combines **written explanations** with **live, editable code** that runs directly in your browser. No installation required.

- **Read** the theory and intuition
- **Run** the code cells to see results
- **Edit** the code, change parameters, break things, build intuition

The chapters build on each other. The early parts develop the mathematical language (linear algebra, probability, geometry) that the later algorithm chapters depend on.
